# Build checklist

- [ ] Clone the official Kuira Starter.
- [ ] Run the starter before changing anything.
- [ ] Copy `contract/src/proof_counter.compact` into the starter contract source directory.
- [ ] Compile the Compact contract using the starter's documented toolchain.
- [ ] Deploy the contract using the Kuira recipe.
- [ ] Call `increment()` from the Android app.
- [ ] Confirm the ledger value changes.
- [ ] Run the proof on a physical Android phone.
- [ ] Capture a screenshot or short screen recording showing the proving flow.
- [ ] Put the evidence in the repository or link to it publicly.
- [ ] Update `docs/SPRINT_NOTES.md` with real results.
- [ ] Publish an X thread/blog/video linking to this public repository.
